# NutriEasy Flutter MVP

Bu klasor, NutriEasy'nin cross-platform Flutter gecis iskeletini icerir.

## Durum

- Native Swift iskeleti referans olarak korunur.
- Ana mobil gelistirme Flutter tarafinda devam eder.
- Flutter CLI bu makinede kurulu olmadigi icin proje dosyalari elle scaffold edildi.

## Calistirma

Flutter kurulu bir makinede:

```bash
cd flutter_app
flutter pub get
flutter run
```
